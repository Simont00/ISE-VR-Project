# ASD Real-Time Monitoring & Sensory Intervention System

### Overview
An AI-powered system designed to assist children with Autism Spectrum Disorder (ASD). It uses Computer Vision to monitor emotional states and triggers calming sensory interventions (music) automatically when high stress is detected.

### Tech Stack
- **Backend:** Flask (Python)
- **AI/ML:** DeepFace, OpenCV, TensorFlow
- **Frontend:** HTML5, CSS3, JavaScript (Real-time polling)
- **Audio:** Pygame Mixer

### Features
- Real-time emotion detection (Happy, Sad, Angry, etc.)
- Automated Music Therapy trigger based on stress threshold.
- Live Analytics Dashboard for parents/caregivers.
